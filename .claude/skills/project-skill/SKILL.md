# LabMate — Project Knowledge

- 12 portable skills; five Claude named agents with ordinary-subagent/main-thread
  fallback. Read-paper packets retain source coverage and page/equation/figure locators.
- Four lifecycle handlers: existing session context, silent commit-maintenance
  records, once-per-session pending summary before compaction, Git advisory.
  Ordinary directories do not require initialization. Hooks do not grant permission.
- Pipeline state and experiment structures are owned by typed scripts. Pending
  maintenance uses atomic local state; failed commands are not completed commits.
- Package, both manifests and README badges share version 0.11.0.
  Release checks do not change user installations; commit inner repository before
  the outer marketplace gitlink. Plugin install and legacy links are alternatives.
- Run tests/test-hooks.sh, test-platform-compat.sh, test-context-contract.sh and
  test-scripts.sh for a release. Payload fixtures do not prove live host trust.
