# Experiment analysis story patterns

This optional reference supplies narrative patterns, not a separate style or
required slide count. Use research-slides for research Beamer decks and the
active project profile for HTML. Do not migrate existing artifacts automatically.

## Ablations
Establish the question, configuration matrix and metrics before comparing results.
Explain each unfamiliar variable before interpreting its effect. Separate main
results, component ablations, failure cases and the conclusion supported by them.
A compact experiment may fit a few slides; do not manufacture fifteen slides.

## Detection or review benchmarks
Define the injected condition, reference verdict, detection criterion and false
positive/negative denominators. Show representative actual cases and uncertainty.
A configuration ranking is not a model capability conclusion outside that setup.

## Evidence and visual choice
Use exact result files, run IDs, configs and original case reports. Summaries are
navigation, not substitutes for traceable measurements. Abstracts establish paper
scope, not full-paper details. Choose a small table, plot, comparison or schematic
for the relation being explained; do not force animated bars or finding cards.

Keep source manifests, legible labels, metric directions and uncertainty.
Only present findings supported by inspected artifacts; no fixed quota of
objectives, cases or conclusions. Existing historical decks remain unchanged.
